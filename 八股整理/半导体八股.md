### ⁠1. 什么是flash
Flash（闪存） 是一种非易失性存储器，断电后数据不丢失，可以电擦除和重新编程。
### ⁠2. 你对NAND Flash和NOR Flash有什么了解？
AND和NOR是Flash的两种类型，核心区别在存储单元的连接方式。NOR是并联结构，支持随机读取，所以适合存Bootloader和固件。NAND是串联结构，密度高、成本低、写入快，但只能按页读写、按块擦除，所以NAND适合大容量数据存储，比如SSD和U盘。

## ⁠4. 内存的存储和读取速度是否和主控芯片的性能相关
相关，但主控和存储介质各自决定不同的部分。NAND Flash 的页读取时间、编程时间、擦除时间是物理下限，这是介质本身决定的。主控芯片通过多通道并行、DMA 搬运、SRAM 缓存、硬件 ECC、多核调度来掩盖 NAND 的延迟，提升整体带宽和 IOPS。
## ⁠5. DMA
### ⁠5.1. DMA的概念
DMA（Direct Memory Access，直接存储器访问） 是一种让数据在外设和存储器之间、或存储器和存储器之间直接传输的机制，不需要 CPU 参与搬运。
### ⁠5.2. 你项目中是如何使用DMA的
DMA 是我项目里最核心的底层技术之一。我用 DMA 把 DCI 图像数据搬到 SRAM，用双缓冲实现采集和处理并行，用传输完成中断切换缓冲区。这套机制和 SSD 主控里 NAND 到缓存的 DMA 搬运逻辑完全一致——都是让 CPU 专注计算和调度，数据搬运交给 DMA。理解 DMA 的配置、双缓冲、中断协同和错误处理，是我做固件开发最重要的基础之一。
### ⁠5.3. DMA 循环模式和普通模式的区别
普通模式传输完指定长度就停止，需要重新配置才能再传。循环模式传输完后自动重新开始，适合连续采集场景。我们图像采集用循环模式，DMA 一直工作，不需要 CPU 反复配置。
### ⁠5.4. DMA是如何进行配置的
配置 DMA 时，我主要设置了源地址为 DCI 数据寄存器、目标地址为 SRAM 图像缓冲区，传输长度为一帧图像的像素数，数据宽度为 16 位以匹配 RGB565 格式，传输方向为外设到内存，源地址固定、目标地址自动递增，传输模式设为循环模式以支持连续采集，同时使能了传输完成中断，并配置了 NVIC 优先级，让 DMA 搬完一帧后能及时通知 CPU 切换缓冲区。
